## Stop-the-line invariants

| Invariant                                        | Executable evidence / required outcome                                                                      | Status       |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------- | ------------ |
| No unreviewed public media                       | Pending/private search/detail/origin denial in integration + real staging                                   | NOT VERIFIED |
| No uploader self-approval                        | UPLOADER 403 and non-owner reviewer guard; no decision/audit mutation                                       | NOT VERIFIED |
| No original private upload served publicly       | Private quarantine GetObject denied; unsupported ORIGINAL alias 404; only re-encoded outputs served         | NOT VERIFIED |
| No duplicate independent public asset on retry   | Intent/complete replay + worker crash/retry unique job/variant assertions                                   | NOT VERIFIED |
| No inconsistent derivatives from concurrent jobs | SKIP LOCKED + lease token fencing + conditional writes/version/hash pins; concurrent integration assertions | NOT VERIFIED |
| No false Host send/post confirmation             | Exact selected message; callback once; no Host write requests in real staging                               | NOT VERIFIED |
| No post-takedown uncached origin access          | Response gate and subsequent detail/display/poster 404; stale Picker denied                                 | NOT VERIFIED |
| No secret/private storage identifier leakage     | Allowlisted DTO/log/error assertions; full B08 log-hygiene and DB log checks                                | NOT VERIFIED |
| No claims of unexecuted passing tests            | CI result/count/step/artifact verification against exact run SHA                                            | NOT VERIFIED |

A NOT VERIFIED, BLOCKED or FAIL criterion prevents declaring the First Buildable Slice closed. A reported historical pass is not silently promoted to a new B09 pass. External rights/privacy/production approval is assessed independently in [release gate](B09-release-gate.md).
